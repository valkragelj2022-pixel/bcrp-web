BlueCity Roleplay — site + admin panel
1. Install Node 18+ on your host (VPS, Render, Railway, etc.)
2. In this folder run:  node server.js   (built-in admin: zeus / zeus123 — change it in Admin → Accounts)
   (without those vars a random owner password is printed once in the console)
3. Website: http://localhost:3000   Admin: footer link "Ekipa · Admin"
Owner + developer = full access: edit packages, peds, MLOs, team, rules, settings,
upload images, manage accounts. Data lives in data/ and uploads/ (back them up).
NOTE: the site now needs server.js running (GitHub Pages / plain static hosting won't save edits).
